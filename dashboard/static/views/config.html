Android mobile guide

Goal: route Android app traffic through Ghost-Hunter/Burp and inspect it from the dashboard.

  1. Start Ghost-Hunter with ./start.sh start.
  2. Set your Android device proxy to your workstation IP on port 8888.
  3. Install the Burp/mitm CA certificate on the device if HTTPS interception is needed.
  4. If the app uses certificate pinning, use your own approved mobile instrumentation workflow (for example Frida) outside this UI.
  5. Browse the mobile app and monitor captured traffic/endpoints in the dashboard.

Note: Android instrumentation is documented here, but not fully automated from the UI.
