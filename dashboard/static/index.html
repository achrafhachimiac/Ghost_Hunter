Android mobile guide

Goal: route Android app traffic through Ghost-Hunter/Burp and inspect it from the dashboard.

  1. Start Ghost-Hunter with ./start.sh start.
  2. Set your Android device proxy to your workstation IP on port 8888.
  3. Install the Burp/mitm CA certificate on the device if HTTPS interception is needed.
  4. If the app uses certificate pinning, use your own approved mobile instrumentation workflow (for example Frida) outside this UI.
  5. Browse the mobile app and monitor captured traffic/endpoints in the dashboard.

Note: Android instrumentation is documented here, but not fully automated from the UI.

Burp plugin setup guide

This local guide explains how to install Jython, load the Ghost-Hunter Burp plugin, connect it to the dashboard, and start sending Burp-scoped traffic into Ghost-Hunter.

1. Download Jython standalone

Burp needs the standalone Jython JAR to run Python extensions.

https://www.jython.org/download

Recommended file: jython-standalone-2.7.x.jar

2. Load Jython into Burp

  1. Open Burp Suite.
  2. Go to Extender → Options.
  3. Find the Python Environment section.
  4. Select the downloaded jython-standalone-2.7.x.jar.

3. Install the Ghost-Hunter Burp plugin

  1. Go to Extender → Extensions.
  2. Click Add.
  3. Extension type: Python.
  4. Select this file:
burp_extension/ghost_hunter.py

4. Connect Burp to the local dashboard

  1. Start Ghost-Hunter with ./hunt.sh start.
  2. Open the Burp tab named Ghost-Hunter.
  3. Set the API URL to:
http://127.0.0.1:1010

Then click Save & Test Connection.

5. Important: define Burp scope first

  1. Open Target → Scope in Burp.
  2. Add only the domains and paths you are authorized to test.
  3. Browse the target normally.
  4. The plugin will forward Burp-scoped traffic to Ghost-Hunter.

Quick checklist

✅ Ghost-Hunter running: ./hunt.sh start

✅ Burp plugin loaded: burp_extension/ghost_hunter.py

✅ Jython configured in Burp

✅ Burp scope configured

✅ API URL set to http://127.0.0.1:1010
